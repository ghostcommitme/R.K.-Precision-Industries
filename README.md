# R K Precision Industries - Next.js

Responsive Next.js site for R K Precision Industries.

## Run locally

1. Install Node.js (18.18 or newer).
2. Open a terminal in this folder and run `npm install`.
3. Run `npm run dev` and open the local URL shown in the terminal.

The website uses externally hosted Unsplash photography and Google Fonts. The contact form redirects to WhatsApp with a prefilled enquiry message.
